P7S Open

Got a signed .p7s file and your Mac/PC can't open it? Drop it here: you get the original document back and see who signed it and when. Runs 100% in your browser — the file never leaves your device.

What is a .p7s file?

It is a CMS / PKCS#7 container: the original file plus one or more digital signatures (for example a Ukrainian КЕП made with Diia or id.gov.ua, or an EU qualified signature). Operating systems don't know how to open it, so the document looks "broken". The document is still inside, untouched.

This page reads the container with a small ASN.1 parser written in plain JavaScript, takes out the embedded document and lists the certificates of the signers. It does not check that the signature is cryptographically valid (that needs the CA's trust lists) — for an official check use your government's signature verification service.

If the result says the signature is detached, the .p7s contains only the signature and the original file was sent separately.
